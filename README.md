# АрмаПласт — демонстрационный сайт

Статический сайт в стиле интернет-магазина инженерных товаров: шапка с каталогом, поиск, слайдер акций, категории, карточки товаров с фильтрами, блоки «Доставка и оплата» и «Контакты».

Каталог построен по структуре сайта-образца: 12 крупных разделов (акции, бытовая сантехника, мебель и аксессуары для ванной, водонагреватели, насосы, водоснабжение, инструменты, кухонные мойки, отопление, приборы учёта, плитка) и 24 демонстрационных товара с фильтрами. Клик по категории применяет соответствующий фильтр и прокручивает к товарам.

Кнопка «Корзина» в шапке открывает панель с выбранными товарами: количество можно менять, удалять позиции и видеть итоговую сумму. Оформление заказа — демонстрация, данные никуда не отправляются.

В разделе «Контакты» встроена карта Яндекса с отметкой адреса (координаты `56.308550, 43.823754`). Клик по карте открывает карточку дома `Московское шоссе, 302а` на Яндекс.Картах в новой вкладке.

## Структура

```
index.html              — разметка всех разделов
assets/css/style.css    — стили (адаптив от 1100 до 640 px)
assets/js/main.js       — слайдер, меню, фильтры, поиск, корзина, модальное окно
assets/img/*.svg        — собственные векторные иллюстрации и иконки
.nojekyll               — чтобы GitHub Pages не игнорировал файлы
```

## Запуск локально

Просто откройте `index.html` в браузере. Для проверки через локальный сервер:

```powershell
python -m http.server 8000
# http://localhost:8000
```

## Важно перед реальным использованием

Контактные данные в файле `index.html` — **заглушки**, замените их на настоящие:

- телефон `+7 (950) 615-11-00` (в шапке, в разделе «Контакты» и в подвале);
- адрес `Нижний Новгород, Московское шоссе, 302а`;
- e-mail `info@armaplast.example`;
- цены и перечень товаров — демонстрационные.

Форма «Заказать звонок» не отправляет данные никуда — это только демонстрация интерфейса. Для приёма заявок подключите бэкенд, Telegram-бота или форму стороннего сервиса.
